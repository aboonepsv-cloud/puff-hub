# Puff Store Hub

Static front end for the Puff Store Hub. Google Drive and Sheets are the backend. This site is the interface.

## Files
- `index.html` — page structure
- `style.css` — layout and colors
- `app.js` — navigation and chat panel

## Local preview
Open `index.html` in a browser.

## Deploy
Hosted on Cloudflare Pages. Push changes to this repo and the live site updates automatically.

## Next
Forms will submit through Apps Script to store folders and tracker Sheets. Chat is local-only until that is wired.
